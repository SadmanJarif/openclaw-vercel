Why this isn't the full local dashboard
The real Control UI is served by the long-running Gateway and talks to it over WebSocket on port 18789. Vercel functions time out after 10s and are stateless, so this version gives you the same dashboard view with on-demand chat/webhook, not a gateway that stays awake.

Sessions

webchat — current browser session
No persistent sessions on Vercel — functions are stateless, so sessions don't survive between requests. On a local gateway, your sessions, memory and channel connections live in ~/.openclaw/.

To turn chat on
1. Create a free key at openrouter.ai/keys — no card needed.
2. Vercel → openclaw-vercel → Settings → Environment Variables → add OPENROUTER_API_KEY.
3. Redeploy. Then /api/health will show hasKey: true.
