📱 WhatsApp — Not linked on Vercel
Real OpenClaw links WhatsApp with a QR code: openclaw channels login --channel whatsapp, then on your phone WhatsApp → Settings → Linked Devices → Link a Device and scan it. WhatsApp uses Baileys (WhatsApp Web), not the official API, and it needs the long-running Gateway — Vercel serverless can't hold that QR session, so the full link has to happen on a local gateway / VPS. Save your number below and it will be kept for that setup.



Tip: use a second / assistant number if you can — linking your personal WhatsApp makes every message to you become agent input.

Settings — API key

OpenRouter API key
Paste your free key once. It is saved in this browser only (localStorage) — never in the repo, never on the server. Every time you open this dashboard on this device it will already be there, you don't need to enter it again. To remove it, use Clear below or clear this site's data.

Get a free key: openrouter.ai/keys — sign up with GitHub/email, no card. Free models: 20 req/min, 50 req/day.

Or set it in Vercel (all devices)
Vercel → openclaw-vercel → Settings → Environment Variables → OPENROUTER_API_KEY, then redeploy. The browser key above takes priority for chats from this browser.
